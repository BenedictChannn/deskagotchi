Small, local, and honest about the beta.

Deskagotchi is a Windows-first indie beta. The landing page links to GitHub Releases for the installer; the app itself keeps normal pet state on your machine.

GitHub-hosted installer

Download the Windows installer only from the official GitHub Release. The release notes should include the exact installer checksum before public sharing.

Unsigned beta caveat

If the v0.1 build is unsigned, Windows may show SmartScreen or Unknown Publisher warnings. Verify the GitHub Release source before running it.

Local in normal use

No account, no analytics, no remote telemetry, and no remote sync in normal use. Pet state is stored locally and the Settings panel shows the data path.

v0.1 scope

Windows first. Built-in pets only. Custom pet generation and import/export are intentionally held for a later release.
