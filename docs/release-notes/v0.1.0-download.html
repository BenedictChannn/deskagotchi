v0.1.0 Scope

  • Windows installer.
  • Built-in pets only.
  • Feed, play, clean, sleep, medicine, pet, and status flows.
  • Tray recovery and local save state.

Privacy

Deskagotchi stores normal state locally in Electron's userData directory. v0.1.0 does not require an account, analytics, telemetry, or remote sync.

Known Limits

  • No custom pet import/export in v0.1.0.
  • No macOS public download unless separately tested.
  • Unsigned builds may trigger Windows trust warnings.
