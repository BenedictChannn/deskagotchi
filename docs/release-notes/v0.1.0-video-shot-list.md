# Deskagotchi v0.1.0 Release Video Shot List

Record this only after the Windows release candidate installer is built. The
video should show the exact release-candidate app, not a dev server or a future
feature branch.

## Claim Rules

- Show Windows only unless macOS has separate smoke evidence.
- Do not show custom pet loading/import/export.
- Do not show custom pet generation.
- Do not mention signing unless the release is actually signed.
- Keep captions scoped to "free Windows-first beta" unless the release scope
  changes.

## Suggested Shots

1. Download page with `Download from GitHub Releases`.
2. First launch after install.
3. Pet sitting on the desktop overlay.
4. Drag the visible pet around the desktop.
5. Open compact care actions from the pet.
6. Feed, play, clean, and sleep actions.
7. Open Settings.
8. Use tray/menu recovery or reset position.
9. Show local data/privacy line: no account, no analytics, no remote sync.
10. End card: Windows installer, GitHub source, checksum in release notes.

## Evidence To Keep

- Release candidate commit.
- Installer path.
- Recording date.
- Unsigned build caveat wording used for the release.
- Any manual checks completed before recording.
