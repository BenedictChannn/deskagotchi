Deskagotchi v0.1.0 release notes.

Deskagotchi v0.1.0 is a Windows-first desktop companion beta. It ships the built-in pet roster, local care simulation, tray recovery, settings, and Windows installer packaging.

Trust And Signing

If this build is unsigned, Windows may show SmartScreen or Unknown Publisher warnings. That warning means Windows cannot verify a publisher certificate for the installer; it does not by itself prove the app is unsafe.

Before publishing, add the exact installer checksum:

SHA256: <fill after building the final installer>

Privacy And Local Data

Deskagotchi v0.1.0 does not require an account, analytics, remote telemetry in normal use, or remote sync. Normal app state is stored locally in Electron's userData directory. The Settings panel shows the resolved local data path. QA harnesses can write local event logs only when explicit QA mode is enabled.

  • deskagotchi-save.json
  • deskagotchi-save.backup.json
  • reserved package directories, if created by older development builds

Uninstalling the app removes the installed application files. Local user data may remain so users can preserve or manually reset their pet state.

v0.1.0 Scope

Included:

  • transparent desktop pet overlay
  • built-in pets: Bao, Miso, Mochi, Peanut, and Puddles
  • feed, play, clean, sleep, medicine, pet, and health/status flows
  • tray/menu recovery and quit actions
  • always-on-top, startup, reduced motion, low maintenance, and notification settings
  • local save/backup recovery

Not included:

  • custom pet import/export
  • custom pet generation
  • macOS public downloads without macOS smoke evidence
  • code signing unless release signing is added before publish

Release Evidence To Fill Before Publish

  • pnpm run check
  • pnpm run qa
  • five-minute idle QA
  • pnpm run qa:release
  • pnpm run qa:v2:closeout
  • manual acceptance export or explicit deferral for physical checks

Known Limitations

  • Windows-first v0.1.0 beta.
  • Unsigned builds may trigger SmartScreen.
  • Manual checks are still required for interactive installer UI, startup-on-login, sleep/wake, unusual taskbar placement, and monitor setups.
  • Custom pets are intentionally held for a later release.

Reporting Issues

When reporting a bug, include:

  • Deskagotchi version
  • Windows version
  • whether the installer was signed or unsigned
  • what action you were taking
  • whether the issue happens after restarting the app
  • screenshots or screen recording when useful
