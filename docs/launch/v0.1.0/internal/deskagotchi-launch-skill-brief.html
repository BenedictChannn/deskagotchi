Default Framing

Small on purpose. Warm, handmade, and honest.

Deskagotchi is a free Windows-first indie desktop pet beta: a tiny virtual companion for people who miss checking on a little digital creature. It should not be framed as productivity software, wellness software, an AI companion, or a serious life-changing product.

Operating Loop

Use this whenever drafting a launch asset or weekly content batch.

01 Read context

Load positioning, release notes, download page, target QA artifacts, and relevant repo truth.

02 Find proof

Use screenshots, clips, installer evidence, QA reports, or visible product behavior.

03 Draft variants

Write channel-native landing, X, Reddit, release, or demo-video copy.

04 Truth pass

Map claims to evidence, check source state, and remove unsupported claims.

05 Follow up

Track replies, downloads, objections, bugs, useful language, and next posts.

Reddit

Trust Gates

These checks keep warm copy from becoming inaccurate launch copy.

Before publishable release copy

  • Read the target release notes and download page.
  • Check installer name, signed or unsigned status, and SHA256.
  • Include SmartScreen wording when the build is unsigned.
  • State Windows-first scope and current known limits.

Before validation claims

  • Read the target QA run's report.md plus machine artifacts like summary.json.
  • Check whether evidence came from a dirty worktree.
  • Use narrow wording such as tested scope, not broad "validated" claims.
  • Map every public claim to a source or artifact.

Public Copy Boundaries

These rules are where most launch mistakes would happen.

Use

  • Virtual pet nostalgia.
  • Handheld digital-pet feeling.
  • LCD toy feel.
  • Tiny care loop.
  • No analytics or remote telemetry in normal use.

Avoid

  • Trademarked comparison phrases in public copy.
  • Loneliness, mental-health, wellness, or productivity claims.
  • Taskbar-resident wording unless the exact visual supports it.
  • LinkedIn-style corporate positioning.
  • Vote asks, engagement pods, or generic support requests.
